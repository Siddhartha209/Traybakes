# Traybakes AI Catalyst

An AI marketing system prototype that generates marketing content and conducts market research.

# Features
Competitor research using web search and LLM analysis to find what works in similar campaigns
Caption generation with iterative self-refinement
Image generation that matches your products and brand assets
Learning from feedback: thumbs up/down and your manual edits shape future captions
Edit before publishing: tweak content without regenerating everything
Desktop interface built with PySide6
